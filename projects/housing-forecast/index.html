// 01 — approach

How the model
was built

A four-stage pipeline from raw CBS open data to interactive provincial forecasts — built to be reproducible and extendable.

1
⬇
Data Collection

Pulled housing price data directly from CBS StatLine via the OData API. Tables 83625NED (average sale prices per region) and 85773NED (price index 2020=100) covering 2015–2024.

cbsodata CBS API Kadaster
2
Feature Engineering

Created lag features (t-1, t-2), YoY growth rates, and 3-year rolling averages per province. Label-encoded regions and added polynomial year terms to capture non-linear trends.

Pandas Lag features Rolling avg
3
Model Training

Time-based split: trained on 2015–2021, tested on 2022–2024. Compared Linear Regression, Random Forest, and Gradient Boosting. Best model selected by R² score.

Scikit-learn Cross-validation MAE · RMSE · R²
4
Visualisation

Interactive Plotly charts: price trends per province, % growth bar chart, actual vs predicted scatter, feature importance, and an iterative 2025–2027 forecast with rolling lag updates.

Plotly HTML export Forecast loop

// 03 — insights

Key findings
from the data

Four patterns stood out when analysing a decade of Dutch housing data across all twelve provinces.

01
Randstad premium is widening

Noord-Holland, Utrecht, and Zuid-Holland consistently outpace the national average. By 2024, prices in Amsterdam's province are 2.3× those in Zeeland — a gap that's grown every year since 2017.

02
Lag-1 is the strongest predictor

Feature importance analysis showed that last year's price (prijs_lag1) explains over 68% of the model's predictive power — more than region, year, or growth rate combined.

03
2022 dip was short-lived everywhere

Rising mortgage rates caused a brief cooling in 2022–2023 across all provinces. By 2024, prices had recovered and exceeded pre-dip levels in 10 out of 12 provinces.

04
Forecast: +8–14% growth by 2027

The Gradient Boosting model projects continued growth across all provinces through 2027. Flevoland and Utrecht show the steepest forecasted trajectories, while Zeeland and Drenthe grow more modestly.

# Feature engineering + model training

import cbsodata, pandas as pd
from sklearn.ensemble import GradientBoostingRegressor

# Pull live from CBS OData API
df = pd.DataFrame(cbsodata.get_data('83625NED'))

# Create lag features per province
df['prijs_lag1'] = df.groupby('regio')['gem_prijs'].shift(1)
df['yoy_groei']  = df.groupby('regio')['gem_prijs'].pct_change() * 100
df['prijs_ma3']  = df.groupby('regio')['gem_prijs'].transform(
    lambda x: x.rolling(3, min_periods=1).mean()
)

# Time-based split: train 2015–2021, test 2022–2024
