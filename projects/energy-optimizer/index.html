// 01 — pipeline

Five-step analysis
pipeline

From raw CBS energy delivery data to actionable SME savings recommendations — fully automated end-to-end.

⬇
CBS API

Live data pull via cbsodata from table 84901NED — gas & electricity delivery per sector

Feature Eng.

Per-address normalisation, kWh-equivalents, gas/electricity ratio per SBI sector

Elbow + Sil.

Optimal k via elbow method and silhouette score — auto-selected per dataset run

K-means

StandardScaler + KMeans (n_init=20) on 4 features, PCA for 2D visualisation

Savings

Benchmark vs lowest cluster · 2024 NL MKB tariffs · per-address & aggregate

geschatte jaarlijkse besparing · alle MKB-adressen in hoog-risico clusters
Gas is de grootste kostenpost

In clusters 2 en 4 verklaart aardgasverbruik 60–70% van de totale energiekosten. Overstap op warmtepompen of WKO-systemen heeft de hoogste ROI voor MKB.

Elektra-cluster profiteert van solar

Cluster 3 (elektra-intensief) toont gemiddeld 340+ zonnedagen potentieel. Terugverdientijd zonnepanelen MKB: 4–6 jaar bij huidig netverbruik.

SBI-sector voorspelt cluster sterk

Bedrijfstak (SBI-code) is de sterkste clusterpredictor. Horeca en productie-MKB zitten consistent in hoge-verbruiksclusters — ongeacht bedrijfsgrootte.

Benchmarking werkt als interventietool

Door bedrijven hun clusterplaatsing te tonen t.o.v. sector-benchmark ontstaat een concrete, gepersonaliseerde besparingsdoelstelling — effectiever dan generieke adviezen.
